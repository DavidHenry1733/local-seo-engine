1. Hub Page Inclusion
Every campaign sitemap must include:
- campaign hub page
- all cluster pages
- any supporting/blog pages assigned to that campaign

If the hub page is missing, fix the sitemap builder so it includes pages where:
- pageType = hub
- isHubPage = true
- hubTag = hub
- or any existing hub identifier used by the app

Do not only include cluster/area pages.

2. Campaign Sitemap vs Master Sitemap
We need two clear sitemap types:

A. Campaign sitemap
Includes only pages for one campaign:
- hub page
- cluster pages
- supporting pages

B. Master project sitemap
Includes all selected/published pages across all campaigns.

Make sure both are generated correctly.

3. URL Rules
Sitemap XML entries should use the live client website domain from Business Profile / Publishing Setup.

Example:
https://clientdomain.com/local-seo-rotherham/
https://clientdomain.com/local-seo-aston/

The app-hosted sitemap route can exist, but the URLs inside the XML must be client live URLs, not app preview URLs.

4. App-Hosted Sitemap Route
The app-hosted sitemap route is acceptable for copying into Search Console only if it serves XML containing the correct client-domain URLs.

However, the UI must clearly label it:

- App-hosted sitemap URL
- Live-site sitemap URL if uploaded to FTP
- FTP upload status

Do not confuse these two.

5. Slug Generation Lock
Create one central slug/path helper for all page types.

Rules:
Hub page:
- /{service-slug}-{primary-location-slug}/

Cluster page:
- /{service-slug}-{area-slug}/

Supporting/blog page:
- /{article-slug}/ or existing supported format

Do not generate bare area slugs.

All campaign generation, sitemap generation, page preview, export, FTP upload, and internal linking should use this same helper.
