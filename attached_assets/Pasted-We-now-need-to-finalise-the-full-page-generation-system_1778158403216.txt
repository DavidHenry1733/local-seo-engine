We now need to finalise the full page generation system so every page is consistent, premium, and scalable.

Do not change:
- overall page structure
- image system
- section order

We are combining:
- content engine
- image placement
- CTA system
- internal linking
- related services section

---

========================
1. CONTENT STRUCTURE
========================

Each page must follow:

- H1 (service + area)
- Quick Answer block
- Local introduction
- Trust section (image)
- Service explanation
- Local context section
- Problem section (image)
- Service breakdown
- Process section
- Proof/trust section (image optional)
- Related Services section
- Final CTA section (with conversion image)

---

========================
2. IMAGE SYSTEM
========================

Use exactly 4 images per page:

- heroImage → split hero section
- trustImage → early section
- supportImage → mid page
- conversionImage → full-width before CTA

Rules:
- All images 16:9
- Split images: 45–50% width
- Conversion image: full-width (max height controlled)
- Use hybrid layout:
  - short text beside image
  - longer content below full width

---

========================
3. CONTENT RULES
========================

- Human tone, not generic AI
- No repetitive phrases like “we offer”
- Short paragraphs (2–3 sentences)
- Inject local context 3–4 times:
  - nearby areas
  - business types
  - customer behaviour
- Use problem → impact → solution structure
- Include 2–3 mini Q&A style answers inside content

---

========================
4. CTA SYSTEM (DYNAMIC)
========================

Each page must include:

Mid-page CTA (optional):
- Short prompt + button

Final CTA section:
- Heading
- Short paragraph
- Primary button
- Secondary option

CTA must change based on service type:

SEO / Web / Marketing:
- “Request a Free Review”
- “Request a Free Audit”

Trades:
- “Request a Quote”
- “Request a Callback”

Professional services:
- “Book a Consultation”

Personal services:
- “Book an Appointment”

CTA must:
- reduce friction
- feel relevant to service
- link to configurable URL (contact, audit, booking)

---

========================
5. INTERNAL LINKING SYSTEM
========================

Each page must include 3–6 internal links.

Rules:
- Prioritise service hub pages
- Then related services
- Then area/service pages if relevant
- Include contact/audit link

Do not:
- over-link
- repeat exact anchor text
- link unrelated pages

Anchors must be natural:
- “local SEO services”
- “website hosting support”
- “professional web design”

---

========================
6. RELATED SERVICES SECTION (IMPORTANT)
========================

Add a designed section before final CTA.

Heading:
Related Services

Intro paragraph:
Explore related services that can help improve your visibility, strengthen your online presence, and generate more enquiries in [Area] and nearby locations.

Display:
- 4 service cards (max)
- Grid layout:
  - desktop: 4 columns
  - tablet: 2 columns
  - mobile: stacked

Cards must include:
- service title
- short 1–2 sentence description
- CTA link

Selection rules:
- Include current service hub
- Include 3 related service hubs

Example (web design page):
- Web Design
- Local SEO
- Website Hosting
- Google Business Profile OR Email Marketing

Do NOT:
- show cluster area pages here
- show more than 4 items
- leave section empty

Styling:
- clean card layout
- spacing above and below
- visually balanced (not just text links)

---

========================
7. LOCAL CONTEXT INJECTION
========================

Use area data to inject:

- nearby areas (2–4)
- business types
- customer behaviour

Inject in:
- intro
- local context section
- problem section

Do not overuse or repeat wording.

---

========================
8. FINAL GOAL
========================

Each page must feel:

- written for that specific area
- visually designed, not templated
- useful for real users
- structured for SEO and AI extraction
- consistent across all services

Not:

- generic
- repetitive
- bulk-generated
