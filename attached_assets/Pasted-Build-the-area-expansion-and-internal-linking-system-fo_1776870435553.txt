## 4. Area page behaviour

Each area page must:
- link back to the Sheffield hub page
- link to 2–3 related nearby area pages

## 5. Internal linking rules

Implement these rules:

### Hub page
Links to:
- all area pages for that city/service

### Area page
Links to:
- hub page
- up to 3 sibling area pages

Example:
web-design-ecclesall links to:
- web-design-sheffield
- web-design-fulwood
- web-design-crookes
- web-design-hillsborough

Keep links relevant and clean.
