Prompt builder logic:
1. Normalise the businessType key before lookup.
   Examples:
   - "coffee shop" should resolve to "coffeeShop"
   - "beauty salon" should resolve to "beautySalon"
   - "nail clinic" should resolve to "nailClinic"
   - "window cleaner" should resolve to "windowCleaner"
   - "personal trainer" should resolve to "personalTrainer"
   - "community pharmacy" should resolve to "communityPharmacy"
   - "interior design" should resolve to "interiorDesign"
   - "pet grooming" should resolve to "petGrooming"

2. Look up the role scene:
   const roleScene = businessTypeSceneMap[normalisedBusinessType]?.[imageRole]

3. If no exact business type match exists, use the generic role scene fallback:
   heroImage:
   "a professional local business carrying out its main service in a clean, trustworthy UK setting"

   earlySupportImage:
   "a clear service-in-action scene showing tools, equipment or process related to the service"

   problemImage:
   "a realistic customer problem or service issue being solved professionally"

   trustImage:
   "a friendly professional consultation or workmanship scene that builds confidence"

   conversionImage:
   "a clean finished result showing the successful outcome of the service"

4. Build the final Ideogram prompt using this format:

wide angle composition, subject centred, designed for website layout with space around subject, create a photorealistic modern commercial website image for a [businessType] business. The image is for the [imageRole] section of a local SEO landing page targeting [primaryKeyword] in [location]. Show [roleScene]. The image should feel relevant to [shortPageDescription or primaryKeyword]. Realistic UK setting, clean professional composition, natural lighting, high detail, premium local business website style, no text, no logo, no watermark, no brand names, no writing, no signage, no captions, no overlays, no distorted hands, no unrealistic faces.

5. Keep Ideogram output aspect ratio at 16:9.

6. Keep existing AI image save behaviour:
   - generated image should be saved back to the correct business type image library
   - user should be able to select it like any other library image

7. Add console logging for debugging:
   - raw businessType
   - normalisedBusinessType
   - imageRole
   - selected roleScene
   - final prompt sent to Ideogram
