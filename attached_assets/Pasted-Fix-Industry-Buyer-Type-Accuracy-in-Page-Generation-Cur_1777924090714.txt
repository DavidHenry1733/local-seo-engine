Fix Industry + Buyer Type Accuracy in Page Generation

Current issue:
The landscaping page copy is unacceptable because it assumes “businesses” and “commercial ROI” for a service that is often household/homeowner focused. The engine must distinguish whether the service is aimed at households, businesses, landlords/property managers, or mixed audiences before generating copy.

Do not change layout, sitemap, deployment, social distribution, image library, or link audit unless validation requires it.

Goal:
Add buyerType and audienceIntent logic so every page writes content for the correct customer type.

==================================================
1. Add buyerType to campaign/service setup
==================================================

Add required field:

buyerType:
- household
- business
- landlord-property
- mixed

Examples:
Landscape gardener = household by default
Plumber = household + landlord-property by default
Roofer = household + landlord-property by default
Electrician = mixed by default
Clinic/aesthetics = household/individual by default
Web design = business by default

Allow user override.

==================================================
2. Add audienceMode to generation context
==================================================

Every page generation prompt must include:

serviceName
industryType
buyerType
customerProfile
location
targetAudience
primaryBuyerPainPoints
primaryConversionAction

The AI must never guess whether it is B2B or B2C.
